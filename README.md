# Портфолио — статичный сайт из Notion

Копия оформления публичной страницы Notion «Кейсы» (pavlovdesign.notion.site) и трёх кейсов с артефактами. Чистый HTML + CSS, без JS. Светлая тема как на notion.site, тёмная — автоматически по `prefers-color-scheme`.

## Структура

```
index.html                     главная «Кейсы»
cases/bilet-beru.html          кейс «Билет Беру» + cases/bilet-beru/*.html (5 артефактов)
cases/geovizor.html            кейс ГЕОВИЗОР + cases/geovizor/*.html (6 артефактов)
cases/afisha.html              кейс «Глобальная афиша» (подстраниц нет)
assets/css/style.css           все стили (цвета Notion — переменные в :root)
assets/img/<кейс>/<артефакт>/  картинки, имена — как файлы в Notion
assets/video/                  видео Афиши (из Notion) и ролик ГЕОВИЗОРа
tools/                         скрипты пересборки из Notion
```

Все ссылки относительные.

## Как открыть

Дважды щёлкнуть `index.html`: сайт работает с диска, сервер не нужен.
Видео «Билет Беру» подгружаются с s3.twcstorage.ru, поэтому без интернета не играют.

## Как выложить

- **Netlify Drop**: открыть https://app.netlify.com/drop и перетащить папку `portfolio-site` целиком.
- **GitHub Pages**: положить содержимое папки в корень репозитория (или в `docs/`), затем Settings → Pages → Deploy from branch. Файл `index.html` должен лежать в корне публикуемой папки.
- Любой статический хостинг (Vercel, Cloudflare Pages, S3) тоже подойдёт: просто залить файлы.

После публикации стоит заменить относительный `og:image` в `<head>` на абсолютный URL (`https://<домен>/assets/img/...`): мессенджеры не понимают относительные ссылки в превью.

## Что обновлять при изменении кейса

Тексты переносились из Notion без правок. Если кейс в Notion поменялся, проще пересобрать страницы, чем править HTML руками:

```bash
mkdir -p /tmp/pf/raw
python3 tools/fetch.py /tmp/pf/raw <id главной> <id кейсов и артефактов…>   # список id — в PAGES в tools/build.py
python3 tools/build.py /tmp/pf/raw .            # пересобирает все HTML и пишет /tmp/pf/downloads.json
python3 tools/dl.py /tmp/pf/downloads.json .    # докачивает новые картинки (между запросами пауза, Notion отвечает 429)
node tools/check.cjs . /tmp/pf/shots index.html # битые картинки и ссылки, снимки 1440/390
```

- Страницы читаются из публичного API notion.site, поэтому новая страница должна быть опубликована в Notion.
- Новую подстраницу нужно добавить в словарь `PAGES` в `tools/build.py` (путь html, папка картинок, родитель).
- Видео, загруженные в Notion файлом (как у Афиши), качаются по подписанной ссылке через Notion MCP (`get-file-download-urls`), ссылка живёт около 5 минут.
- Ролик ГЕОВИЗОРа лежит локально (`assets/video/geovizor-flow1.mp4`, тёмная тема). Запасной источник — внешний файл из Notion (`flow1-light.mp4`).
- Ссылок на рабочий прототип или стенд ГЕОВИЗОРа на сайте нет, и добавлять их не нужно.
- Свойства базы Notion (Навыки, Статус, Порядок и другие) на страницы кейсов не переносятся.
